# Cheat Engine Lua Documentation Reference

Cheat Engine ships its own official Lua API reference (`celua.txt`) under Cheat Engine's repository terms rather than this bridge's MIT license. To keep licensing boundaries clean, this repository links to the upstream documentation instead of redistributing a verbatim copy:

- Official `celua.txt` in Cheat Engine's repository: https://github.com/cheat-engine/cheat-engine/blob/master/Cheat%20Engine/bin/celua.txt
- Cheat Engine Wiki (Lua API & tutorials): https://wiki.cheatengine.org/index.php?title=Lua
- Local copy installed with Cheat Engine: `<Cheat Engine install dir>\celua.txt`

For this bridge's own JSON-RPC command catalog and implementation notes, see:
- `AI_Context/MCP_Bridge_Command_Reference.md`
- `AI_Context/AI_Guide_MCP_Server_Implementation.md`
